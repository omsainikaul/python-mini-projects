# Snake Game (Python Basics)

This is a polished, playable Snake game implemented with Tkinter.

How to run:

1. Ensure you have Python 3 installed (Tkinter is included in standard Windows Python installs).
2. Run:

   python Projects/snake_game.py

Controls:
- Arrow keys or WASD: move
- P: pause/resume
- Enter: restart after game over

High score is saved to `snake_highscore.txt` in the same folder as the script.

No external dependencies required.

Enjoy!

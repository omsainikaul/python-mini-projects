# Python Mini Projects

A collection of beginner Python mini projects built while learning Python and strengthening my programming fundamentals.

These projects helped me practice problem-solving, Python syntax, functions, file handling, working with libraries, and building small practical applications.

## Projects

### 01. Snake Water Gun

A command-line version of the classic Snake-Water-Gun game where the user plays against the computer.

**Concepts Used:**
- Conditional statements
- Functions
- User input
- Random module
- Game logic

---

### 02. File Organizer

A Python program that automatically organizes files into different folders based on their file extensions.

**Concepts Used:**
- File handling
- `os` module
- `shutil` module
- Loops
- Conditional statements

---

### 03. Typing Speed Tester

A command-line typing test that measures typing speed and accuracy using randomly selected sentences.

**Concepts Used:**
- Functions
- String manipulation
- Time measurement
- Random module
- Accuracy and WPM calculation

---

### 04. Quiz App

A command-line quiz application that asks multiple-choice questions and calculates the user's final score.

**Concepts Used:**
- Lists and dictionaries
- Loops
- Conditional statements
- User input
- Score tracking

---

### 05. PDF Merger

A GUI-based Python application that allows users to select multiple PDF files and merge them into a single PDF.

**Concepts / Libraries Used:**
- Tkinter
- pypdf
- File dialogs
- GUI development
- Exception handling

---

### 06. Water Drinking Reminder

A Python program that sends desktop notifications at regular intervals to remind the user to drink water.

**Concepts / Libraries Used:**
- `time` module
- Plyer notifications
- Loops
- Automation

---

### 07. Password Manager

A command-line password manager that can save passwords and retrieve them when needed by copying them to the clipboard.

**Concepts / Libraries Used:**
- File handling
- Functions
- Pyperclip
- User input
- String processing

> **Note:** This is a beginner learning project and is not intended for storing real or sensitive passwords.

---

### 08. Snake Game

A Python implementation of the classic Snake game.

**Concepts Used:**
- Game logic
- Loops
- Conditional statements
- Functions
- Keyboard controls

---
